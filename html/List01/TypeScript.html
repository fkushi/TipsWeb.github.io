JavaScriptとは

動きのあるWebページが現代では多用されている。
そのような「動き」を実現するためには裏でプログラムされたアプリケーションが動作する。
このブラウザ上で動作する唯一のプログラミング言語が、JavaScriptです。

altJSとは

altJSとは、ブラウザで動作するアプリケーション開発の複雑化による
生産性の低下の問題を解決するために作られた新たな言語である。

altJSはJavaScriptへ変換されることを前提に作成される。
流れを下記に記す。

altjsコード ➡ コンパイラ ➡ JavaScript ➡ 主要なブラウザで動作


※altJSでは、JavaScriptへの変換をすることをコンパイラと呼んでいる

altJSとして、現在筆頭として位置を占めているのがMicrosoftによって作られたTypeScriptです。

◇npm

Node Package Managerの頭文字をとったもの。
Node.jsのパッケージ管理システムである。
この名称通りのnpmコマンドを利用して、様々なパッケージのインストールや
アンインストール、アップデートなどの管理が行える。

連想配列

キーと値のペアで一つの要素となる仕組みである。
※C++の言語だとmapと同じ処理。
連想配列では、要素を管理するためのデータをキー、管理されているデータの方を値という。

<構文>
const heightList: {[key: string]: number;} = {...}

構文説明
heightList連想配列変数名
{}連想配列を表す
key: stringキーのデータ型
number値のデータ型
<記述例>どの値が誰の伸長かを区別したい場合
const heightList:{[key: string]: number;} =
{
   "Tomoko": 155.4,
   "Yumi": 162.3,
   "Ayaka": 157.9
};
for(const key in heightList){
   console.log('${key}さんの身長: ${heightList[key]}');
}
