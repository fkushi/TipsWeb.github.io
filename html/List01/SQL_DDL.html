DDLとは

DDL：Data Definition Language オブジェクトの定義に関わるものである。下記がDDL文となる。

オブジェクトDDL説明
表
基本となるオブジェクト		CREATE TABLE表を作成する
ALTER TABLE表の定義を変更する
DROP TABLE表を削除する
TRUNCATE TABLE票のすべての行を削除する(切り捨て)
ビュー
データアクセスを制限する		CREATE VIEWビューを作成する
ALTER VIEWビューを有効化する。
また、ビュー制約を変更する。
DROP VIEWビューを削除する
シーケンス(順序)
一意な数値を生成する		CREATE SEQUENCEシーケンスの作成
ALTER SEQUENCEシーケンスの属性を変更
DROP SEQUENCEシーケンスの削除
索引
問合わせの
パフォーマンス向上		CREATE INDEX索引の作成
ALTER INDEX索引を変更する
DROP INDEX索引を削除する
シノニム
オブジェクトに
別名を指定する。		CREATE SYNONYMシノニムを作成する
ALTER SYNONYMシノニムを変更する
DROP SYNONYMシノニムを削除する

制約とは

制約(整合性制約)は、票の列に対して設定したルールである。
ルールに違反するデータが格納されることを禁止する。

制約を適切に設定することで、データベースに不適切なデータが格納されることを防ぐ。
※データの内容の整合性を維持できる
